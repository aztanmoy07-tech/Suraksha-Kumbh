## 🛡️ Key Capabilities

### 1. 🔱 Prayagraj Sangam 3D Digital Twin
* **Three.js WebGL Engine**: 3D spatial twin of Triveni Sangam, Akbar Fort, Saraswati Ghat, Arail Ghat, and floating Pontoon Bridges 1-5.
* **Hydrodynamic River Simulation**: Multi-frequency wave rippling reflecting the holy confluence of Ganga & Yamuna.
* **Tactical QRBs (Rescue Boats)**: Animated NDRF & SDRF patrol motorboats cruising the Sangam perimeter with dynamic rocking.
* **Crowd Flow Streams**: 200 animated crowd particle streams crossing pontoon corridors toward Sangam Nose.
* **Holographic CDSI Beacons**: Interactive cylinders and ground safety rings pulsing with live Crowd Density Safety Index telemetry.
* **Aarti & Day/Night Mode**: Shift between golden hour sunlight and night Aarti with warm floating temple diya lighting.
* **2D GIS & 3D Command Switch**: Instant 1-click toggle in the Command Center map between 2D Leaflet spatial radar and the 3D Digital Twin.

### 2. 📻 Zero-WAN Offline Tactical Walkie-Talkie & Mesh Messenger
* **100% Offline Communication**: Functions with zero internet, zero cellular towers, and zero cloud dependencies using local `BroadcastChannel` P2P and multi-hop packet routing.
* **Web Audio Walkie-Talkie Chirps**: Pure browser synthesizer emitting authentic tactical radio mic key-up and incoming transmission squelch beeps.
* **5 Dedicated Channels**: `🚨 EMERGENCY`, `👮 POLICE & QRT`, `🏥 MEDICAL CORPS`, `🚩 SEVADARS`, and `📢 PUBLIC`.
* **Instant Quick-Transmit Presets**: 1-tap situational broadcasts (e.g., *Crowd surge at Sangam*, *Stretcher required at Pontoon 4*).
* **Persistent Local Storage**: Offline conversations automatically saved and retained across reloads.

### 3. 🌐 8-Language Pan-India Localization
* Native support for: **English**, **हिन्दी (Hindi)**, **मराठी (Marathi)**, **বাংলা (Bengali)**, **தமிழ் (Tamil)**, **తెలుగు (Telugu)**, **ગુજરાતી (Gujarati)**, and **ਪੰਜਾਬੀ (Punjabi)**.

### 4. 🚑 Intelligent Resource Allocation & Stampede Routing
* Real-time automated resource dispatches for water tankers, ambulances, mahaprasad, blankets, and barricades.
* Odd/Even pilgrim ID alternating evacuation corridors to eliminate bottlenecks.

## 🛠️ Local Development

```bash
# 1. Clone repository
git clone https://github.com/OjshwiRaj/SURAKSHA-KUMBH.git
cd SURAKSHA-KUMBH

# 2. Install dependencies
npm install

# 3. Start local server
PORT=3001 npm start
```
* **Command Center**: `https://localhost:3001/`
* **3D Sangam Twin**: `https://localhost:3001/prayagraj_twin.html`
* **Pilgrim Companion**: `https://localhost:3001/User_Interface.html`
