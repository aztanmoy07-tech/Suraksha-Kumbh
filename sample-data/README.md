# Sample Data

The JSON files in this folder are synthetic fixtures for development and demonstrations. They do not represent real pilgrims, volunteers, locations, incidents, or operational events.

Use them only if their schema matches the application's actual data model. Adapt field names and required properties after inspecting the source code.

- `sample_alerts.json` — illustrative alert records.
- `sample_crowd_data.json` — illustrative zone-level crowd metrics.
- `sample_users.json` — fictional user/role examples with no real contact details.
